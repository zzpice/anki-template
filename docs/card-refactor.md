# 卡片模板重构验收

本分支为 `refactor/card-templates`，从 main `9ad147acbf687b61116043a3ce19aff03cad5043` 创建。仅修改卡片模板、直接运行资源、生成预览、测试及相关文档。正式 `downloads/anki-template.apkg` 保持原样；本分支的新版通过 `build/review.apkg` 临时验证，不用于正式分发。首页、网页制卡业务及其存储格式不变。

## 分析与方案

2026-10-18 核对官方最新稳定版 [Anki 26.09.3](https://github.com/ankitects/anki/releases/tag/26.09.3)。实现以该版本的官方 Python 后端与 reviewer 为依据，并复核仓库原有 Anki 25.09.2 基线。

原系统已有完整的原生分卡及导图能力。重构保留这些学习能力，重写通用运行脚本、视觉基础和各类信息层级，重新组织导图工具；不为重构而替换可靠的原生功能或复制一套 Cloze 解析器。

| Anki 能力 | 本方案的选择 |
| --- | --- |
| [笔记与字段](https://docs.ankiweb.net/manual/editing) | 五个独立笔记类型；现有可选字段已经区分问题、答案、解释与出处，因此保持精简结构，不引入 JSON 字段或特殊编辑器 |
| [原生 Cloze](https://docs.ankiweb.net/manual/editing#cloze-deletion) | 分卡、同编号分组、提示、嵌套与答案 HTML 全部由后端生成；自定义交互只消费生成标记 |
| [原生 Image Occlusion](https://docs.ankiweb.net/manual/editing#image-occlusion) | 保留 stock 类型身份及字段 tag，继续使用官方编辑器、矩形、椭圆、多边形、分组和两种模式 |
| [HTML 与脚本生命周期](https://docs.ankiweb.net/manual/templates/styling#javascript) | 处理 reviewer 复用 WebView、FrontSide 脚本重复执行和解析期先后顺序；当前卡片 DOM 拥有事件，不挂全局快捷键 |
| [媒体](https://docs.ankiweb.net/manual/media) | 静态脚本带下划线，随集合媒体离线同步；无 CDN、远程字体、运行库或网络接口 |
| [MathJax 与音频](https://docs.ankiweb.net/manual/math) | 保留原生渲染和媒体标记，不另建数学或音频播放器 |

### 设计依据

参考 `zzpice/zzp-platform` main `0d9ffea83a7567a0744d69bacdbcc6aff286c808`（2026-10-18）的 `packages/ui/src/tokens.css`、Home / Assets / Hub 的基础样式与控件：暖纸色 `#faf9f5`、陶土橙 `#bd531a`、石墨深色 `#151617`、细边框、8 / 12 / 16px 圆角和 44px 触控目标。卡片自包含维护这些少量值，不依赖另一个仓库的服务或构建流程。

复习界面使用单列 720px 阅读区、题型与章节顶部标记、问题 / 参考答案 / 解析 / 折叠补充 / 来源的稳定层级。正文 18px，手机问题约 19.4px，长内容不强制适应一屏。无背景图、装饰性动画、侧栏和复习统计。

### 数据和代码边界

- `cards/note-types.json` 是五类笔记的唯一规格，字段和 ID 无须改变。本次没有使用旧笔记兼容层；保留字段只是因为它们能直接表达所需数据。
- `cards/style.css` 负责公共排版、主题、富文本、选择题和图片查看器。
- `cards/media/_review.js` 按选择题状态、背面核对、填空增强、内容增强和原生遮挡初始化拆分函数。模板不把字段插入 JavaScript 字符串。
- 问答与选择的背面共享；两次模板脚本在答案 DOM 到位后完成一次核对，避免浏览器解析顺序造成选择题无答案标记。
- 导图继续独立脚本与附加样式；复用经验证的原生标记、树规范化和搜索算法，重新安排工具层级与触控控件。
- 不加前端依赖、构建框架或长期复习数据库。选择和导图各只使用一个临时 `sessionStorage` 条目，换到新正面即覆盖或清除。

| 复杂填空降级 | 嵌套、缺少原生 `data-cloze`、块级或交互内容、MathJax 公式保持原生显示，不启用逐项按钮；不自行解析或改写复杂答案 |

| 遮挡失败保护 | 遮挡绘制完成前原图不可见；缺少 API、同步或异步初始化失败时隐藏原图并提示使用支持的客户端 |
| 思维导图 | 原生 Cloze + 普通嵌套列表；分支折叠、逐项与全部显隐、定位本卡、循环下一处、全文搜索、结果循环、路径展开、翻面临时状态全部保留 |

| 富文本 | 中文、英文、RTL、ruby、列表、引用、代码、表格、图片保留；宽内容局部滚动；链接继续使用 Anki 原生处理 |
| 离线与状态 | 系统字体、本地媒体、零网络依赖；无 localStorage 复习记录，无评分或排程 API 调用 |

## 复现检查

依赖准备见 [维护说明](development.md#生成与检查)。本分支不要运行无参数构包命令覆盖公开安装包。

```sh
.venv/bin/python scripts/build_package.py --output build/review.apkg
.venv/bin/python scripts/check_templates.py
ANKI_TEST_PACKAGE=build/review.apkg ANKI_RENDER_OUTPUT=build/cards.json .venv/bin/python -m unittest discover -s tests -v
node tests/test_browser.cjs
node --test tests/test_tools.mjs
ANKI_PYTHON=.venv/bin/python node tests/test_tools_browser.cjs
node tests/test_site.cjs
```

`ANKI_TEST_PACKAGE` 指定待验收的临时包；未指定时仍检查正式下载包。`ANKI_TEST_PREVIEW` 可指定另一后端生成的预览，`ANKI_RENDER_DIR` 可让浏览器读取另一套后端夹具。它们只影响测试，不改变生产构包器。

CI 在临时位置生成验收包，继续运行两个 Anki 版本及 Chromium / WebKit 矩阵；只有 main 的现有发布条件可部署 Pages，本次不运行部署。

### 可选 Desktop 实测

额外安装完整 `aqt` 依赖后运行：

```sh
.venv/bin/python -m pip install aqt==26.9.3
.venv/bin/python tests/desktop_smoke.py
```

它启动官方 aqt / Qt WebEngine，使用唯一实例标识、安全模式和 `build/` 下全新临时配置，不读取个人集合，不登录或同步。通过官方 reviewer 检查 14 张示例的正反面与真实应用主题，共 56 次渲染，并核对选择翻面状态、遮挡画布和无横向溢出。脚本直接切换展示卡片，不模拟真实评分或触控手势；排程保留由后端导入测试覆盖。结果与截图写入 `build/desktop-results.json` 和 `build/desktop-screenshots/`。

## 验证边界

自动检查与最终结果记入交付的验收报告。后端导入、官方 reviewer 浏览器、实际 Anki Desktop、手机尺寸模拟、AnkiMobile / AnkiDroid 实机是不同层次，不能相互替代。

AnkiMobile 与 AnkiDroid 尚未在实体设备验证。特别需要在实际设备确认：WebView 中的模板脚本与临时存储共享、原生遮挡回调、触控手势与应用翻面手势、输入焦点 / 软键盘、横竖屏、媒体同步、系统夜间模式以及音视频播放。原生遮挡缺少所需 API 时会显示提示；存储不可用时不能保留选择，但两面的答案映射不变。导图缺少现代原生标记时保留原生 Cloze，关闭增强工具。

数学和音频沿用原生能力；后端验证了音频标记和内容保留，浏览器不能代替客户端播放与完整数学渲染测试。首次同步必须完成媒体下载；链接到外部网页的来源仍需网络。
